# 討論與決策紀錄

每次討論後，把「決定了什麼、為什麼」記在這裡，最新的放最上面。

## 2026-11-05

**決定**

- 做一個字音字形練習網頁，給國中生（準備會考）和高中生（準備學測）在課後自己練習。
- 題型有四種：選出正確讀音、找出錯別字、同音或形近字辨析、多音字判讀。作答都用點選。
- 題庫先由 Claude 寫初版，老師審核後才上線；之後老師可以自己新增，或用 Excel 一次匯入。
- 額外功能有四項：錯題本（用五個盒子安排複習）、教師後台、遊戲化設計、記憶小故事。
- 學生用「班級代碼＋座號＋暱稱」登入，不收集真實姓名。
- 程式由 Claude 開發。
- 技術方案：規格書和程式碼放在 GitHub，網頁用 GitHub Pages 發布；學生答題紀錄存在 Firebase（Firestore）資料庫，教師後台從這裡統計。

**還沒決定的事**

- 學生登入要不要加 4 位數密碼？
- 要不要顯示班級排行榜？
- 課本讀音和教育部辭典不同時，以哪個為準？
- 程式名稱要不要用「字字珠璣」？
- 介面要不要用「紙感書房」風格？

- Firebase 使用免費的 Spark 方案，不綁信用卡。
- GitHub 儲存庫已建立：github.com/chiafeng-914/zizizhuji（公開）。
- 所有檔案除了備份到 GitHub，也依任務分類存在老師電腦桌面的 ClaudeAI 資料夾。
