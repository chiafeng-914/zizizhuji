# 字字珠璣｜字音字形練習程式

給國、高中生課後自主練習字音字形的網頁程式。老師可以在後台看到全班最常錯的字，回到課堂精準補強。

## 資料夾說明

| 位置 | 內容 |
| --- | --- |
| `docs/開發規格書.md` | 完整開發規格 |
| `docs/討論與決策紀錄.md` | 每次討論決定的事項 |
| （之後新增）程式碼 | 網頁程式，使用 GitHub Pages 發布 |

## 技術

- 網頁：GitHub Pages
- 資料庫：Firebase（Firestore），存放學生答題紀錄

學生資料只存在 Firebase，不會放進這個 GitHub 儲存庫。
